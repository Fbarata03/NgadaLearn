# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest (main branch) | ✅ |

## Reporting a Vulnerability

To report a security vulnerability, please **do not** open a public GitHub issue.

Instead, send an email to: **suporte@ngadalearn.pt**

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 72 hours and work to resolve the issue promptly.
